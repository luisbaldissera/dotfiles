# Laio context

Baseline created: 2026-10-31 on Arch Linux.

## Managed paths

- Repository template: `config/_default.yaml`
- System template: `${XDG_CONFIG_HOME:-$HOME/.config}/laio/_default.yaml`
- Arch package definition: `package/PKGBUILD`
- Deployment and installation: `sync.sh`
- Package name: `laio-bin`
- Pinned Laio version: 0.18.0

## Current state

- Laio is the preferred layout and session manager for tmux.
- The official Arch repositories and the AUR did not contain a Laio package when this component was initialized.
- The component therefore wraps Laio's official, statically linked Linux release archive in a local Arch package and installs it through Pacman.
- The package supports the upstream Linux architectures `x86_64` and `aarch64`, verifies their pinned SHA-256 checksums, depends on tmux, and installs Bash, Zsh, and Fish completions generated by the pinned binary.
- The managed `_default.yaml` creates a project-rooted tmux session with an editor window running Neovim and a terminal window containing two side-by-side Zsh panes.
- Named global configurations and project-local `.laio.yaml` files remain user- or project-owned.
- The component has not been deployed to the live system.

## Configuration model

- Laio reads named global configurations from `${XDG_CONFIG_HOME:-$HOME/.config}/laio/*.yaml`.
- `laio config create NAME` renders `_default.yaml` into a named global configuration. Laio supplies `session_name` from `NAME` and `path` from the current directory.
- A project-local `.laio.yaml` is discovered from the current directory or its parents when `laio start` is run without a name.
- tmux is Laio's default multiplexer. Sessions started by Laio add `prefix M-l` as a Laio session switcher inside those sessions.

## Operational notes

- `sync.sh` builds and installs `laio-bin` only when the pinned package version is not installed. Package installation can prompt for `sudo` through `makepkg`/Pacman.
- Configuration sync is one-way, skips an identical template, and backs up a changed destination below `${XDG_STATE_HOME:-$HOME/.local/state}/config-agents/backups/laio/` by default.
- `--dry-run` performs no downloads, package builds, package installation, or configuration writes.
- Starting, stopping, linking, deleting, or exporting Laio sessions is deliberately outside sync.
