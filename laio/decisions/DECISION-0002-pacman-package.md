# DECISION-0002: Install a pinned upstream release through Pacman

- Status: Accepted
- Date: 2026-10-31

## Context

The preferred installation interface is Pacman, but neither the official Arch repositories nor the AUR contained a Laio package at initialization. Upstream publishes statically linked Linux archives and SHA-256 checksums for x86_64 and aarch64.

## Decision

Maintain `package/PKGBUILD` for a local `laio-bin` Arch package. Pin Laio 0.18.0 and the checksums of both supported Linux archives. Build with `makepkg` and install or upgrade through Pacman only when the pinned package version is absent.

The package depends on tmux and installs shell completions generated by the pinned Laio binary.

## Consequences

Pacman owns the installed files and can query or remove the package normally. Upgrades require an explicit review of the upstream release, version, asset names, and checksums before updating the repository. A live sync requires network access and may prompt for `sudo`.
